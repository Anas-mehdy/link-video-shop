# المراجعة النهائية للهاتف

الفرع `ux/dashboard-workspace`. بُني التعديل على تغييرات إعادة التصميم المحفوظة في `d8474c1`.

- الحجز المسبق: بطاقات هاتف فقط تعرض رقم الطلب وحالته والمخصص من الإجمالي. أسباب المراجعة، غياب توثيق الموافقة، تعليق كامل الطلب وتأخر الدفعات تظهر خارج التفاصيل بالاعتماد على الحقول نفسها. لا تُحسب جاهزية شحن من الكمية. المنتج واللون واسم العميل والمواعيد وتوثيق الموافقة داخل details أصلي؛ الفتح والإغلاق لا يعيدان رسم القائمة أو يطلبان بيانات. إجراءات الدفعات الحالية محفوظة.
- الإعلانات: الفترة والمنصة والتطبيق في مساحة أصغر على الهاتف. حقلا التاريخ يظهران للفترة المخصصة فقط. الحقول المخفية معطلة عن التحقق الأصلي للنموذج، والتطبيق يحسب الفترة الجاهزة من تعريفها الحالي. تغيير إظهار الحقول وحده لا يطلب تقريرًا. فلاتر الكمبيوتر باقية ظاهرة وقابلة للتحرير.

## دليل التحقق

`node --test tests/preorders.test.js tests/preorder-order-plans.test.js tests/snapchat-reporting.test.js tests/tiktok-reporting.test.js`: نجح 22 اختبارًا دون تخطٍّ.

مع تشغيل `npm start`:

```sh
REVIEW_PHASE=before PLAYWRIGHT_MODULE=/tmp/link-ui-tools/node_modules/playwright node scripts/dashboard-mobile-final-review.cjs
REVIEW_PHASE=after PLAYWRIGHT_MODULE=/tmp/link-ui-tools/node_modules/playwright node scripts/dashboard-mobile-final-review.cjs
```

تُقرأ أصول «قبل» من git عند `d8474c1` دون تعديل ملفات العمل (يمكن تخصيص `REVIEW_BASE_REF`). كل API معترض، ولا يُسمح بأي وجهة خارجية أو خدمة خلفية. كل البيانات اصطناعية. يحفظ الاختبار صورًا ونتائج في `/workspace/link-ui-review/final-mobile`.

نجحت عروض 360 و390 و430: البطاقة والتفاصيل دون تجاوز عرض الصفحة، Enter وSpace للفتح والإغلاق، الاحتفاظ بالفلتر والصفحة دون طلبات إضافية، رفض نطاق مخصص معكوس، ثم إرسال نطاق آخر 30 يومًا الصحيح، ثم تجاوز قيم مخصصة مستقبلية/فارغة عند الرجوع إلى «اليوم» وإرسال تواريخه الصحيحة. التحقق من الاستعلامات صادر عن الطلبات المعترضة نفسها؛ يجري مسح cache في harness فقط لضمان إمكان فحص طلب جديد عند كل عرض.

عند 390 بدأت المؤشرات عند y=936 بدل y=1236، أي أبكر بنحو 300px. عند 1440 كانت صور الحجز والإعلانات متطابقة بكسليًا قبل وبعد بالبيانات والإعدادات نفسها؛ بقي جدول الكمبيوتر ظاهرًا وبطاقات الهاتف مخفية. لا تغيير في API أو SQL أو منطق الشحن أو حساب المؤشرات.

حدود الفحص: Chromium ببيانات محاكاة وخط النظام البديل بعد حجب الخط الخارجي؛ لم يُختبر جهاز هاتف فعلي أو Safari أو إنتاج. لا ادعاء امتثال كامل للوصول.
