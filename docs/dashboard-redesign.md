# إعادة تنظيم لوحة لنك

الفرع: `ux/dashboard-workspace`. لم يُدفع أي فرع ولم يُنفّذ نشر.

## قرارات تجربة الاستخدام

- القائمة القديمة كانت تسرد 16 وجهة دون فصل المهام اليومية عن إعداد القنوات والسجلات. أصبحت الوجهات ضمن المتجر، الأتمتة، التسويق، المحتوى، الحجز المسبق، والإعدادات والتكاملات. بقيت مسارات hash القديمة كما هي.
- الرئيسية القديمة جمعت شرح المشروع وخطوات إطلاقه مع سبعة مؤشرات وقائمة تكاملات. أصبحت تعرض حالة تفويض سلة دون الخلط بينها وبين المزامنة والإرسال، أربعة مؤشرات من البيانات الفعلية، مهام سريعة وآخر الأحداث. القيم غير المعروفة تبقى —.
- ردود أكواد الخصم أصبحت وجهة مستقلة داخل الأتمتة. واتساب مخصص لإعداد الرقم والمسودات؛ أُخفيت تبويبات المحادثات وجهات الاتصال التي لا تحتوي وظيفة منفذة. لم تُضف وجهة منتجات فارغة؛ عدد المنتجات ما زال ظاهرًا، والبحث عن المنتجات متاح في الأدوات الحالية.
- المزامنة وإعدادات تفويض الإعلانات وسجلات الحجز المطوّلة تُعرض عند فتح أقسامها، دون نسخ عناصر التحكم أو إعادة ربط أحداثها. فتح القسم القابل للطي لا يبدأ مزامنة أو إرسالًا.
- إعدادات مساحة العمل لم تعد تعلن أن جميع الأتمتة «اختبار فقط»؛ يجب قراءة حالة كل متابعة في قسمها. احتُفظ بتفسير قبول المزود مقابل التسليم.
- توحيد الوضع الليلي والبنفسجي #51007A وأحجام الحقول والأزرار والجداول، وتحسين التركيز المرئي وتقليل الحركة. القائمة الجانبية قابلة للتمرير مستقلًا. الجداول تتمرر داخل حاوياتها، مع منطقة قابلة للوصول بلوحة المفاتيح.
- أخطاء تحميل الصفحات تعرض إعادة المحاولة مع تفاصيل منفصلة؛ زر تحديث الصفحة يُعطّل أثناء الطلب. يحافظ البحث وترقيم الصفحات على حالتهما عند التنقل بين أقسام السجلات.

## التحقق وإعادته

شغّل `npm start` من جذر المستودع. لا يتطلب العرض المحلي إعداد اتصال إنتاج.

الاختبارات الحالية: `npm test`، وتشمل قواعد البيانات المؤقتة PGlite والتحقق من صلاحيات الإدارة وسلوك الإرسال. اختبار المتصفح الإضافي يستخدم Chromium وPlaywright المثبتين خارج المستودع:

```sh
mkdir -p /workspace/link-ui-review
PLAYWRIGHT_MODULE=/tmp/link-ui-tools/node_modules/playwright node scripts/dashboard-browser-review.cjs after
```

يمكن تثبيت Playwright خارج المستودع باستخدام `npm install --prefix /tmp/link-ui-tools playwright`. يحتاج تشغيل Chromium والوصول المحلي إلى صلاحيات الشبكة المناسبة في بيئة التنفيذ. السكربت يستخدم `/usr/bin/chromium` ويعترض **جميع** طلبات API؛ لا يستخدم بيانات عملاء أو يرسل رسائل. ملفات الصور في `/workspace/link-ui-review`، خارج ملفات التطبيق. صور `before-*` التُقطت قبل التعديل، و`after-*` بعده. البيانات في الصور حالات فارغة/غير متاحة بمحاكاة، وليست بيانات إنتاج.

الاختبار يغطي العروض 360 و390 و430 و768 و1440، عدم تجاوز عرض الصفحة في الرئيسية، التنقل وحالات فشل تحميل الأقسام، إغلاق قائمة الهاتف وإرجاع التركيز، البحث وترقيم الصفحات والاحتفاظ بهما، حفظ رسالة أكواد الخصم بطلب PUT معترض وإعادة محاولة الصفحة. الصور الحالية للرئيسية؛ لا تثبت صلاحية جميع الجداول والنوافذ ببيانات مكتملة.

## حدود النطاق

لم تُغيّر ملفات API أو SQL أو مخططات البيانات أو شروط الأهلية أو توقيت الرسائل أو المزامنة أو سكربتات سلة. الأدوات المضمنة فيديو شوب وحماية الهاتف احتفظت بواجهاتها الحالية داخل الإطار. لم تُختبر جلسة إنتاج أو مزامنة أو إرسال حقيقي أو ربط حسابات. التحقق من الصفحات الديناميكية الناجحة ببيانات كثيرة، تفاصيل الحجوزات ولوحة مفاتيح هاتف فعلية ومراجعة قارئ الشاشة يبقى مطلوبًا قبل تعميم التصميم. لا يُدّعى امتثال كامل لـ WCAG 2.2 AA.

نتيجة التحقق: نجحت الاختبارات الـ288 دون تخطي. لم يرصد axe-core مخالفات WCAG A/AA في الرئيسية عند عرض 390 بمحاكاة الحالة غير المتاحة؛ هذا فحص محدود، وليس شهادة امتثال. صور القائمة وردود الخصم المعبأة ببيانات اختبار محلية متاحة أيضًا.

## جولة التحقق ببيانات كثيفة

أضيف `scripts/dashboard-dense-review.cjs` وبياناته الاصطناعية في `tests/fixtures/dashboard-review/data.cjs`. يستخدم 63 طلبًا و63 عميلًا، 60 حجزًا في 4 دفعات، 16 متابعة بشرية، 30 محاولة خصم، 18 صف معاينة ما بعد البيع، وتقارير إعلانية بمبالغ بالملايين. تشمل الحالات مدفوعًا وجزئيًا وملغى، اعتماد المزود والنتيجة غير المؤكدة، وإلغاء الاشتراك والمراجعة. الأرقام والأسماء اختبارية، والعناوين من example.test.

يُسمح للمتصفح بقراءة `/dashboard` وملفات dashboard JS/CSS من الخادم المحلي فقط. جميع `/api/` تُجاب من الذاكرة، وكل وجهة أخرى تُحجب، بما فيها Google Fonts؛ اللقطات تستخدم خط النظام البديل. لا تُقرأ بيانات Supabase ولا تمر طلبات إلى الخادم الخلفي. Service Workers معطلة. يحظر الاختبار طلبات sync/send/test-send/import/stock-check ويتحقق من عدم حدوثها.

التفاعلات: بحث وترقيم متعدد الصفحات للطلبات والعملاء، العودة مع حفظ حالة البحث، التمرير الأفقي الفعلي للجداول، فتح تفاصيل المتابعة وحفظ الملاحظة، إلغاء نافذة تأكيد الإرسال دون طلب، حفظ تأخير التذكير، حفظ إعدادات ما بعد البيع وفتح تعريف منتج، حفظ رد الخصم، فلترة فترة الإعلانات وتغيير المؤشر وفتح التفصيل اليومي، تعديل دفعة الحجز وحفظها وإغلاقها دون حفظ، فتح اعتماد الاستلام وإلغاؤه، فلترة الحجوزات وترقيمها. حفظ الاختبار يُحدّث بيانات الذاكرة فقط ويُقرأ مجددًا من الواجهة.

الإصلاحات الناتجة: منع انكماش حقول التذكير الثاني، إصلاح تجاوز اسم دفعة طويل على الهاتف، منع التفاف أرقام الإعلانات الكبيرة بتوزيع أنسب على الهاتف، زيادة عرض أعمدة الأسماء والمنتجات، إتاحة تمرير الجداول المضافة بشكل غير متزامن بلوحة المفاتيح، تصحيح تباين toast وبعض النصوص، وإبقاء إعدادات التشغيل وحالته مكشوفة مع طي سجلات الإرسال الطويلة. تصحيح العبارة الثابتة في مراجعة المستحقين لتشير إلى حالة التشغيل الفعلية بدل الادعاء بأن الإرسال غير مفعل.

إعادة الجولة (مع تشغيل الخادم المحلي):

```sh
PLAYWRIGHT_MODULE=/tmp/link-ui-tools/node_modules/playwright node scripts/dashboard-dense-review.cjs
python scripts/build-dashboard-review-gallery.py
```

فحص axe اختياري عبر `REVIEW_AXE=1 AXE_MODULE=/tmp/link-ui-tools/node_modules/@axe-core/playwright`. يمكن تخصيص العروض باستخدام `REVIEW_WIDTHS=360,430,768` والأقسام باستخدام `REVIEW_ONLY=automations,ads,preorders`؛ هذا الوضع يراجع العرض ولا يشغّل تفاعلات الحفظ. تعرض `results.json` الطلبات المعترضة ونتائج الفحص؛ لا تُستعمل نتائج وضع العرض الجزئي لإثبات تفاعلات الجولة الكاملة.

المعاينة في `/workspace/link-ui-review/dense/index.html`: صور مقروءة لكل قسم للهاتف وسطح المكتب، مع روابط الصور الطويلة وصور الفلاتر والإعدادات واعتماد الاستلام. تبقى موافقة المستخدم البصرية، قارئ الشاشة الفعلي، لوحة مفاتيح هاتف حقيقية، اختلافات Safari/Firefox، وأداء اتصال إنتاج خارج هذا التحقق. لا توجد نافذة تفاصيل طلب مستقلة في الواجهة الحالية؛ اختُبرت السجلات ووظائف التفاصيل المنفذة فعلًا بدل اختراع ميزة جديدة.

نتيجة الجولة الكثيفة النهائية: 98 طلب API معترضًا؛ لا أخطاء JavaScript؛ لا مخالفات axe في الأقسام الثمانية المفحوصة عند 390. نجحت فحوص العرض والتفاعلات عند 390 و1440، وأعيد فحص المتابعات والإعلانات والحجز عند 360 و430 و768. نجحت اختبارات المشروع الـ288، ثم 24 اختبارًا للأقسام المتأثرة بعد التعديلات الأخيرة. المعرض متاح أيضًا كأرشيف مستقل في /workspace/link-ui-review/link-dashboard-dense-preview.zip.
